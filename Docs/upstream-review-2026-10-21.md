# بررسی تغییرات Aether

مبنای مقایسه: سورس گذربین `ca0405b` (نسخهٔ 2.2.1)، در برابر شاخهٔ اصلی
[Aether در کامیت 577a4c8](https://github.com/CluvexStudio/Aether/tree/577a4c8)
در تاریخ ۲۰۲۶/۱۰/۲۱. نسخهٔ درج‌شده در Cargo.toml بالادست 2.3.0 است.

موارد جدید یا تغییرکرده نسبت به سورس فعلی گذربین:

| گزینه | تغییر |
| --- | --- |
| `--masque-sni` | انتخاب نام سرور در ClientHello تونل‌های HTTP/3 و HTTP/2؛ پیش‌فرض جدید `www.cloudflare.com` است. |
| `--ech-dns` و `--ech-domain` | انتخاب resolver و دامنه برای دریافت کلید ECH؛ resolver می‌تواند UDP، TCP یا DoH با آدرس و SNI مستقل باشد. |
| `--ech` | در صورت نبود کلید قابل استفاده، اتصال متوقف می‌شود تا نام سرور آشکار ارسال نشود. |
| `--tls-ciphers`، `--tls-groups` و `--disable-grease` | کنترل بیشتر اثرانگشت TLS؛ مسیر API و جست‌وجوی DoH نیز از BoringSSL استفاده می‌کنند. |
| `--api-address` | جایگزین نام قبلی `--enroll-address`؛ امکان تعیین پورت نیز وجود دارد. |
| `--fragment` | علاوه بر HTTP/2 روی فراخوانی‌های API هم اعمال می‌شود؛ گزینه‌های `--api-fragment` و `--no-fragment` حذف شده‌اند. |
| `--gool` | اکنون WireGuard داخل MASQUE است؛ معنای قبلی آن تغییر کرده است. |
| `--gool-classic` | حالت قبلی WireGuard داخل WireGuard با این نام در دسترس است. |
| `--gool-peer` | تعیین مقصد WireGuard داخل تونل MASQUE. |
| `--register` | ثبت هویت و خروج، بدون اجرای اسکن و پراکسی. |
| `--psiphon-cdn-sets` | انتخاب مجموعهٔ لبه‌های CDN برای اسکن Psiphon. |
| `--psiphon-server-entries` | شروع Psiphon با فایل ورودی سرورها. |

همچنین ثبت هویت WARP و بازیابی تونل‌هایی که سریع قطع می‌شوند اصلاح شده و
استفاده از upstream proxy برای برخی ترکیب‌های Tor و Psiphon گسترش یافته است.

این بررسی، هستهٔ گذربین را جایگزین نمی‌کند. ارتقای مستقیم به سورس جدید نیازمند
تطبیق اسکریپت init و اعتبارسنجی گزینه‌های رابط است: رابط فعلی `gool` را
WireGuard داخل WireGuard می‌داند، ولی بالادست معنای آن را تغییر داده است.
افزودن صرفِ گزینه‌های جدید به رابط با هستهٔ فعلی به خطای آرگومان ناشناخته منجر می‌شود.

یادداشت انتشار `5.7.29`: پیش از انتشار، تغییرات با شاخهٔ آنلاین `1c11a7c` ادغام
شدند. آن شاخه قبلاً هسته را در نسخهٔ 2.3.0 ارتقا داده و رابط را برای حفظ معنای
قبلی gool تطبیق داده بود. بنابراین جدول بالا مقایسهٔ تاریخی با نسخهٔ محلی 2.2.1
است؛ برخی گزینه‌های آن در هستهٔ نهایی این انتشار از قبل موجودند.
