# به‌روزرسانی داخلی گذربین

در صفحهٔ گذربین، «بررسی نسخهٔ جدید» نسخهٔ پایدار GitHub را بررسی می‌کند.
اگر بستهٔ سازگار با معماری روتر، خانوادهٔ نسخهٔ OpenWrt و مدیر بسته وجود داشته
باشد، دکمهٔ «به‌روزرسانی برنامه» فعال می‌شود. هسته و رابط LuCI با هم دریافت
می‌شوند؛ Psiphon از نسخهٔ 2.3.0 داخل بستهٔ اصلی قرار دارد. تنظیمات را مدیر بسته حفظ می‌کند.

```sh
gozarbinctl update check
gozarbinctl update status
gozarbinctl update install
```

عملیات در پس‌زمینه اجرا می‌شود. وضعیت در `/var/run/gozarbin-update/state.json`
و خروجی تشخیصی در `/var/run/gozarbin-update/log` قرار می‌گیرد.
دریافت و کنترل همهٔ بسته‌ها پیش از نصب انجام می‌شود؛ نصب با `opkg` یا `apk`
است و تراکنش بازگشت خودکار برای چند بسته فراهم نمی‌کند.

بستهٔ آخر هر جزء همراه فهرست قطعه‌هایش در `/etc/gozarbin/update-cache` نگه‌داری
می‌شود. در به‌روزرسانی بعدی، قطعه‌های مشترک از این بسته خوانده می‌شوند و فقط
بخش‌های متفاوت با HTTP Range دریافت می‌شوند. SHA-256 نتیجه باید دقیقاً با بستهٔ
منتشرشده یکی باشد. اگر کش وجود نداشته باشد، اشتراک کافی نباشد یا درخواست Range
ناموفق شود، دریافت کامل انجام می‌شود. کش خراب نیز هیچ‌گاه نصب نمی‌شود.
هر جزء فقط یک نسل کش دارد و در فضای کم، ذخیرهٔ کش انجام نمی‌شود.
برای آزادکردن فضا می‌توان این پوشه را پاک کرد؛ به‌روزرسانی بعدی کامل خواهد بود.

گردش‌کار انتشار، کنار بایگانی‌های قبلی، بسته‌های مستقل با پیشوند نسخهٔ OpenWrt
و معماری و فایل‌های `.chunks.json` منتشر می‌کند. فشرده‌سازی بسته‌ها با مرزهای
پایدار انجام می‌شود تا تغییر کوچک تمام دادهٔ فشرده را تغییر ندهد؛ قالب قابل نصب
APK/IPK حفظ می‌شود. همهٔ بسته‌ها و manifestها در `SHA256SUMS.txt` درج می‌شوند.
این checksumها از همان انتشار HTTPS دریافت می‌شوند و امضای مستقل انتشار نیستند.

اولین انتشار دارای این دارایی‌ها باید در GitHub منتشر شود تا این قابلیت روی روتر
قابل استفاده باشد. نسخه‌های قدیمی که دارایی‌های تفاضلی ندارند از این مسیر نصب
نمی‌شوند. بررسی فعلی برچسب‌های پایدار `vX.Y.Z` را پشتیبانی می‌کند.

آزمون‌ها:

```sh
python3 test/test-update.py
python3 test/test-delta.py  # نیازمند ucode و ماژول fs
```
